# VoltaLab

Biblioteca de componentes eletrônicos e sete calculadoras: código de cores, lei de Ohm, divisor de tensão, RC, resistor para LED, polarização BJT e temporizador 555.

PWA instalável, com suporte a uso offline.

[Acessar o VoltaLab](https://gustavojacintovoltcalcapp-lgtm.github.io/voltalab/)
